# Кейс: ТЭО проекта «РОДОВОЕ ПОМЕСТЬЕ 2.0: АГРОПОЛИС-КЛАСТЕР»

Цель папки — дать эксперту быстрый вход (10 минут) и возможность глубокой проверки (разделы ТЭО + приложения), без информационного шума.

---

## Как читать (для экспертной оценки)

### Маршрут 10 минут (Executive)
1) [Манифест_Питчбук_Родовое_Поместье.md](Манифест_Питчбук_Родовое_Поместье.md) — короткий питч: проблема → решение → модель → эффекты → запрос.
2) [ТЭО_Родовое_Поместье_Раздел_2_Резюме_проекта.md](ТЭО_Родовое_Поместье_Раздел_2_Резюме_проекта.md) — формализованное резюме (цели, задачи, KPI).
3) [ТЭО_Родовое_Поместье_Раздел_10_Выводы_и_рекомендации.md](ТЭО_Родовое_Поместье_Раздел_10_Выводы_и_рекомендации.md) — итоговая рамка и рекомендации.

### Маршрут глубокого чтения (Due Diligence)
- [ИСТОЧНИКИ_И_БЕНЧМАРКИ.md](ИСТОЧНИКИ_И_БЕНЧМАРКИ.md) — источники/ориентиры для проверки и калибровки допущений.
- Разделы 1–10 ТЭО (Markdown-файлы `ТЭО_Родовое_Поместье_Раздел_*`).
- Приложения (технологии/шаблоны/нормативка/таблицы) — папка [Приложения_Библиотека_Технологий/](Приложения_Библиотека_Технологий/).

---

## Что является «источником правды»
- Markdown-разделы `ТЭО_Родовое_Поместье_Раздел_*.md` — модульная версия (удобна для редакции и экспертных правок по частям).

---

## Как устроена проверяемость
- В конце каждого раздела ТЭО есть блок: **«Источники и бенчмарки / Допущения / Что подтвердить экспертом»**.
- Единый свод источников и шаблоны фиксации допущений: [ИСТОЧНИКИ_И_БЕНЧМАРКИ.md](ИСТОЧНИКИ_И_БЕНЧМАРКИ.md).

## Позиционирование (в одном абзаце)
«РОДОВОЕ ПОМЕСТЬЕ 2.0: АГРОПОЛИС-КЛАСТЕР» — мультидисциплинарный хаб устойчивого развития, который объединяет смарт-агро, ESG-подход, цифровые платформы и кластерную модель экономики для повышения инвестиционной привлекательности сельских территорий и тиражирования практик на уровне регионов.
