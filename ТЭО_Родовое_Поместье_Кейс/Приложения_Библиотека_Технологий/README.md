# 📚 Библиотека Технологий: Инструкция и Структура

## Назначение
Эта папка содержит детальные технические спецификации (Deep Tech), которые поддерживают экономическую модель ТЭО.

## Рекомендация по структуре документа
**Вопрос:** Стоит ли включать эти технологии в развернутом виде в основное тело ТЭО?
**Ответ:** **Нет, рекомендуется оставить их в Приложениях.**

### Аргументация:
1.  **Фокус внимания:** Основной документ (Разделы 1-10) читают инвесторы и чиновники. Им важны: *Деньги, Риски, Сроки, Право*. Детали про "толщину стен" или "протоколы дронов" будут отвлекать от сути бизнес-модели.
2.  **Модульность:** Технологии меняются быстрее, чем экономическая концепция. Оформление в виде Приложений позволяет обновлять "начинку" (например, заменить 3D-печать на модульные блоки), не переписывая всё ТЭО.
3.  **Уровни доступа:**
    *   *Level 1 (ТЭО):* Стратегия и Экономика.
    *   *Level 2 (Приложения):* Инженерные решения и Спецификации.
