# 📚 Библиотека Технологий v3.0: Инструкция и Структура

## Назначение
Эта папка содержит **детальные технические спецификации** с конкретными моделями оборудования, ценами (2025 г.), российскими поставщиками и климатическими адаптациями (ЦФО, −35°C). Документы поддерживают экономическую модель основного ТЭО и служат практическим руководством для застройщиков и резидентов.

## Рекомендация по структуре
**Вопрос:** Стоит ли включать эти технологии в развернутом виде в основное тело ТЭО?
**Ответ:** **Нет, рекомендуется оставить их в Приложениях.**

### Аргументация:
1.  **Фокус внимания:** Основной документ (Разделы 1-11) читают инвесторы и чиновники. Им важны: *Деньги, Риски, Сроки, Право*. Технические детали перегружают.
2.  **Модульность:** Технологии меняются быстрее экономической модели. Приложения можно обновлять автономно.
3.  **Уровни доступа:**
    *   *Level 1 (ТЭО, Разделы 1-11):* Стратегия и Экономика.
    *   *Level 2 (Приложения — эта папка):* Инженерные решения, спецификации, стоимость.

## Принципы отбора технологий (v3.0)
*   ✅ **Проверенные временем** — приоритет серийным, сертифицированным решениям с историей эксплуатации ≥5 лет в РФ.
*   ✅ **Климатическая адаптация** — все решения проверены на работоспособность при температурах −35…+35°C, снеговых нагрузках до 240 кг/м², весенней распутице.
*   ✅ **Доступные поставщики** — указаны конкретные российские производители и дистрибьюторы.
*   ✅ **Прозрачная экономика** — для каждой технологии указаны CAPEX, OPEX, сроки окупаемости.
*   ⚠️ **Инновации — осторожно** — экспериментальные технологии (3D-печать, костробетон, водород) выделены в отдельные «Лаборатории будущего» и не являются обязательными.
