## Оглавление Библиотеки

Данный раздел содержит детализированный технологический стек и операционные протоколы, обеспечивающие реализацию концепции **Neuro-Estate** (Physical Blockchain & Venture Builder). Эти документы предназначены для Technical Due Diligence (TDD) со стороны LP (Квалифицированных Инвесторов) и Синдиката.

3.  **[Энергетика и ЖКХ](03_Энергетика_и_ЖКХ.md)**
