# Руководство по выбору и оценке технологий (дополнение)

Краткий чеклист и критерии оценки технологий, которые следует учитывать при выборе из каталога.

## Критерии оценки
- Техническая зрелость (TRL): 1–9
- Наличие локальных поставщиков и сервиса
- Стоимость владения (TCO) на 5 лет
- Требования интеграции (порты/файлы/API)
- Совместимость с KPI и BI-платформой

## Минимальный паспорт для каждой технологии
- Название решения и поставщик
- TRL и опыт внедрения
- Формат интеграции данных (CSV/JSON/API)
- Основные метрики, которые генерирует система
- Стоимость (CAPEX/OPEX) и пример расчёта окупаемости

## Рекомендация по приоритетам для пилота
1. Энергетика: выбор решения с локальной сервисной поддержкой и возможностью интеграции в BI.
2. Вода/очистка: надёжные биофильтры с минимальными требованиями обслуживания.
3. Строительство: модульные префаб-решения для быстрого старта.
