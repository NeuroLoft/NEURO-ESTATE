# Дополнения к шаблонам документов

Этот файл содержит краткие дополнительные шаблоны и чеклисты, которые должны быть включены в `Шаблоны_документов_ПОДРОБНО.md`.

## 1. Шаблон протокола мониторинга KPI (кратко)
- Название KPI: 
- Метод измерения: (сенсор/лаборатория/отчёт)
- Формат данных: (CSV/JSON/API)
- Частота измерений: (ежедневно/еженедельно/ежемесячно/раз в год)
- Ответственный: (фамилия, роль)
- Порог тревоги и действия: (значение — процедура)

## 2. MVP-checklist для юридических документов
- Типовой договор оператора — готов и адаптирован к региону.
- Устав кооператива — содержит условия членства и механизм исключения.
- Типовой договор членства/доступа к инфраструктуре — есть шаблон и инструкция по заполнению.

## 3. Чеклист интеграции технологии
- Паспорт интеграции: входные данные, метрики, API/файл-формат.
- Минимальные требования к питанию и сервису.
- План обслуживания и гарантийные сроки.

## 4. Формат версионности
- Каждый шаблон получает версию: `vYYYYMMDD` и поле "Источник/комментарий".
