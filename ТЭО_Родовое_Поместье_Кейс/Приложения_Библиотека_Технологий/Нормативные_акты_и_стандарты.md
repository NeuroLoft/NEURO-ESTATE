## 0. MVP-право: что обязательно для пилота

Ниже не «идеальный будущий контур», а минимальный правовой пакет, без которого пилот нельзя считать сделочно и операционно зрелым.

| Контур | Обязательно для пилота | Комментарий |
| :--- | :--- | :--- |
| **Права на участок** | Да | ДКП, аренда, сервитут, схема доступа |
| **Технические условия и подключения** | Да | Электро, вода, связь, дорога хотя бы на предварительном уровне |
| **Договор доступа к Ядру** | Да | HaaS, сервисный договор, правила SLA |
| **Устав кооператива или регламент участия** | Да | Правила членства, взносов, доступа, выхода |
| **Политика обработки данных** | Да | 152-ФЗ, роли доступа, privacy |
| **КРТ, МИП, льготы, sandbox** | Нет, опцион | Апсайд масштаба, но не блокер пилота |
| **ЦФА и сложные цифровые конструкции** | Нет, опцион | Только после валидации бизнес-модели |

**Практический вывод:** сначала исполнимый путь пилота, потом опции институционального масштаба.

| **ФЗ «Об обороте земель с/х назначения»** | от 24.07.2002 №101-ФЗ | Купля-продажа, аренда, ограничения для с/х земель | Ст. 8 (преимущественное право субъекта), ст. 9 (аренда), ст. 4 (макс. площадь) |
| **ФЗ «О ведении гражданами садоводства и огородничества»** | от 29.07.2017 №217-ФЗ | ТСН/СНТ, права собственников, общее имущество | Ст. 3 (понятия), ст. 14 (взносы), ст. 17 (общее собрание), ст. 23 (реестр членов) |
| **ФЗ «О крестьянском (фермерском) хозяйстве»** | от 11.06.2003 №74-ФЗ | Создание КФХ, земля для фермеров | Ст. 3-4 (создание), ст. 11 (земельный участок) |

| **Региональные законы о поддержке сельских территорий** | Различные по субъектам РФ | Субсидии, льготы, бесплатные участки | Калужская обл.: Закон №62-ОЗ; Тульская: Закон №47-ЗТО |

**⚠️ Практический вывод:** Для кластера оптимальная категория — **земли населённых пунктов** (ВРИ: ИЖС, ЛПХ приусадебный) или **земли с/х назначения** (ВРИ: для ведения садоводства/дачного хозяйства). Перевод из с/х в ИЖС через изменение ПЗЗ муниципалитета (6-12 мес.).

## 2. Градостроительное и строительное регулирование

| Документ | Реквизиты | Что регулирует |
|:---|:---|:---|
| **Градостроительный кодекс РФ** | от 29.12.2004 №190-ФЗ | Планировка территорий, разрешения на строительство, КРТ |
| **СП 30-102-99** | Планировка и застройка территорий малоэтажного жилищного строительства | Минимальные расстояния между домами, красные линии, отступы |
| **СП 53.13330.2011** | Планировка и застройка территорий садоводческих объединений | Нормативы для СНТ/ДНТ: 6-12 соток, заборы, противопожарные разрывы |
| **СП 50.13330.2012** | Тепловая защита зданий | Требования к утеплению стен, окон, кровли (ГСОП) |
| **СП 54.13330.2022** | Здания жилые многоквартирные | Нормы инсоляции, вентиляции, звукоизоляции |
| **ГОСТ Р 52398-2005** | Классификация автодорог | Категории дорог (IV-V для подъездной) |
| **СНиП 2.04.02-84** | Водоснабжение. Наружные сети | Пожарные водоёмы, напоры, расходы |
| **ФЗ «О техническом регулировании»** | от 27.12.2002 №184-ФЗ | Техрегламенты, стандарты безопасности |

**⚠️ Практический вывод:** Для домов до 500 м², высотой до 3 этажей — **уведомительный порядок строительства** (ст. 51.1 ГрК РФ). Разрешение на строительство не требуется. Уведомление → 7 рабочих дней → строительство.

## 7. Нормативный чек-лист для Evidence Matrix

| Тезис проекта | Чем подтверждать с правовой стороны |
| :--- | :--- |
| Участок пригоден | выписка, ПЗЗ, карта ограничений, категория и ВРИ |
| Строить можно | уведомительный порядок, проект, схема размещения |
| Подключение возможно | предварительные ТУ, письма сетевых организаций |
| Резидент может жить и пользоваться инфраструктурой | ДКП, договор участия, договор доступа к Ядру |
| Данные собираются законно | политика ПДн, положение о телеметрии, журнал ролей |
| Эксплуатация управляемая | регламент аварий, SOP, акты ответственности |
