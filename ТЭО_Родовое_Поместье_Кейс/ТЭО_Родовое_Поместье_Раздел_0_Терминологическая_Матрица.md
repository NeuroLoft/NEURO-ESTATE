# 📖 Раздел 0. Терминологическая Матрица и Политика Адаптации

Данный документ разработан на базе рекомендаций ИИ-аналитики для обеспечения 100% понятности проекта «Neuro-Estate» для всех категорий стейкхолдеров. Мы используем **Многоуровневый подход** к локализации контента: мы сохраняем премиальность для международных инвесторов, но говорим на юридически чистом языке с государством.

## 1. Цели и Целевые Аудитории (Tone of Voice)

| Аудитория | Стратегия применения терминов | Пример коммуникации |
| :--- | :--- | :--- |
| **Инвесторы (VC/PE)** | Сохранение международных терминов (Оригинал). Фокус на метриках, экзитах и оценке (IRR, CAPEX, Exit). | *«HaaS генерирует стабильный Cash Flow для ЗПИФа.»* |
| **Госструктуры (GR)** | Сухой официоз. Исключение англицизмов. Привязка к законам (СНиП, ФЗ) и Нацпроектам. | *«Инфраструктура как услуга повышает налоговую базу ОЭЗ.»* |
| **Тех. персонал (B2B)** | Смешанная (Гибридная). Профессиональный ИТ/Инженерный сленг. | *«Edge-сервер упал за NAT, поднимаем BESS.»* |
| **Резиденты (B2C)** | Упрощенный русский, акцент на ценность, комфорт и безопасность. Избегаем сложной инженерии. | *«Управление подпиской на умный дом в Супераппе.»* |

## 3. Правила использования в документации ТЭО

1. **Заголовки:** В заголовке должен быть международный маркер для инвестора + русский перевод для госструктур. 
   *(Пример: `Раздел 3. Smart Grid (Интеллектуальная энергосистема)`)*
2. **Финансовые показатели:** Всегда указываются в рублях (RUB) с обязательной припиской *(Base currency)* для иностранных партнеров, если они есть. 
3. **Правовой барьер (Стоп-слова):** В открытой и государственной документации категорически запрещены термины: `Криптовалюта`, `Офшор`, `ICO`, `Токен`. Используем юридически-легитимные аналоги: `ЦФА (Цифровой финансовый актив)`, `Смарт-контракт`, `Утилитарные права`.

## 4. Механизм внедрения новых терминов (SOP Локализации)

Когда в проект внедряется новая инновационная технология, ее терминология проходит 4 этапа адаптации до использования в публичных материалах:
1. **Инжиниринг:** Технический отдел фиксирует английский термин (напр. *Liquid Immersion Cooling*).
2. **Лигал (GR):** Юридический департамент подбирает перевод, соответствующий ГОСТ / СНиП (напр. *Система жидкостного отведения тепла*).
3. **Маркетинг (B2C):** Маркетолог формирует ценностное название для клиента (напр. *Бесшумное эко-отопление*).
4. **Внедрение:** Термин заносится в настоящую Терминологическую Матрицу и одобряется для использования во всех 12 Разделах ТЭО.
