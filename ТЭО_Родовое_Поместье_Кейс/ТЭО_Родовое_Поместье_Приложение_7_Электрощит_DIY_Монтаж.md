# ⚡ Приложение 7. Электрощит Умного Дома: проект монтажа и DIY-инструкция

> **Статус:** Рабочий монтажный проект для электрощита Общего Дома (купольное здание, $9 \times 6$ м).
> **Аудитория:** Один монтажник-DIY, базовые навыки (дрель, отвёртка, изолента, клеммники WAGO, DIN-рейка). Без пайки, без печатных плат.

## 🧭 1. Назначение и общая схема щита

Щит объединяет в одном корпусе: ввод и защиту (автоматы, УЗО), учёт энергии (Zigbee-счётчик) и «умную» коммутацию (Zigbee-реле для экрана и света). Zigbee/Wi-Fi-хабы **физически вне металлического корпуса** (см. §9) — иначе металл экранирует радиосигнал.

| Параметр | Значение |
|---|---|
| Тип корпуса | Навесной пластиковый бокс, **3 ряда × 12 модулей = 36 модулей** (рекомендация: IEK/ЭТМ ET5P, IP41 достаточно — щит внутри помещения) |
| Расположение | Под антресолью, зона коворкинга, рядом с роутером и Tuya-шлюзом (на отдельной полке, вне щита) |
| Высота установки | Низ щита на $1.5$ м от пола (по ПУЭ — от $0.5$ до $1.7$ м для щитков в общественных помещениях) |
| Степень защиты | IP41 (щит внутри каркасного деревянного дома, отделанного вагонкой — IP65 избыточен и дороже на ~30%) |
| Вводной кабель | ВВГнг-LS $3 \times 4\text{ мм}^2$ (с запасом по сечению для суммарной нагрузки $\approx 3.5$ кВт Фаза 1, до $\approx 5$ кВт с Фазой 2) |
| Фазность | Однофазный ввод 220V (трёхфазный не требуется при пиковой нагрузке < 7 кВт) |

> 📋 **Стратегия расширения:** щит на 36 модулей выбран вместо 2×24 по следующим причинам:
> - **Экономия:** один корпус 36 модулей (~2 200 ₽) дешевле двух по 24 (~3 600 ₽ вместе), экономия ~1 400 ₽
> - **Простота монтажа:** одна DIN-рейка для ввода/защиты, одна для умной автоматики, одна для Фазы 2 — логичнее и понятнее
> - **Резерв:** 4 свободных модуля на перспективу (климат, приточка, видеонаблюдение)
> - **Альтернатива 2×24** имеет смысл только если Фаза 2 будет физически в другой пристройке (тёплый модуль для водоснабжения)

## 🔌 5. Схемы подключения по клеммам

### 5.1. Вводной дифавтомат 2P (25А/30мА)
```
 Верх (вход от сети):     [ L ]===[ N ]
                            │       │
                            ▼       ▼
 Низ (выход в щит):       [ L' ]==[ N' ]  → на гребёнку/шину распределения
```

### 5.2. Счётчик электроэнергии Zigbee DIN (устанавливается сразу после дифавтомата, до групповых автоматов)
```
 Клемма 1: L-вход  ◄── от дифавтомата (L')
 Клемма 2: L-выход ──► на гребёнку фазы (к групповым автоматам)
 Клемма 3: N-вход  ◄── от дифавтомата (N')
 Клемма 4: N-выход ──► на шину N
```

### 5.3. Групповые автоматы 1P (×5: Экран, Освещение, Розетки, Чайник, Резерв)
```
 Верхняя клемма: L ◄── от гребёнки фазы (после счётчика)
 Нижняя клемма:  L' ──► к своей нагрузке (реле, розетка, чайник)
 (Ноль N для каждой группы берётся напрямую с шины N, не через автомат)
```

### 5.4. Zigbee-модуль штор (2 канала, интерлок) — питание экрана
```
 Клемма L  ◄── от автомата «Экран» (10А)
 Клемма N  ◄── от шины N
 Клемма P1 (канал 1, «Открыть») ──► WAGO «ЭКРАН L-ОТКР» → мотор
 Клемма P2 (канал 2, «Закрыть») ──► WAGO «ЭКРАН L-ЗАКР» → мотор
 (Подробная схема с проводами мотора — Приложение 6, §5)
```

### 5.5. Zigbee-реле 4-канальное — свет и лента
```
 Клемма L  ◄── от автомата «Освещение» (10А)
 Клемма N  ◄── от шины N (нужна, если модель требует нейтраль на канал — см. §4 BOM Приложения 6, поз.11)

 CH1 (выход) ──► WAGO «ОСВ-РАБ»   → группа рабочего света коворкинга
 CH2 (выход) ──► WAGO «ОСВ-АНТ»   → группа света антресоли
 CH3 (выход) ──► WAGO «ЛЕНТА-БП»  → вход блока питания 12/24V RGB-ленты
 CH4 (выход) ──► WAGO «РЕЗЕРВ-4»  → свободно, для Фазы 2
```
### 5.5а. Zigbee-реле 1-канал — уличный прожектор (Фаза 1.5)
```
Клемма L  ◄── от автомата «Улица/Прожектор» (10А)
Клемма N  ◄── от шины N

Выход ──► WAGO «УЛ-ПРОЖ» → прожектор 220V (50–100Вт, IP65)
                                          на фасаде/входной группе

Zigbee PIR-датчик (уличный IP65):
  ── беспроводной, питание CR123A/CR2
  ── триггерит локальный сценарий на шлюзе:
     «движение → реле ВКЛ → таймер 3 мин → реле ВЫКЛ»
  ── при режиме «Охрана»: движение → сирена + push + запись камеры

```

### 5.5б. Zigbee-реле 1-канал 16A — насос колодца (Фаза 2)
```
Клемма L  ◄── от автомата «Насос» (16А)
Клемма N  ◄── от шины N

Выход ──► WAGO «НАС-КОЛ» → реле давления (обычное, не умное)
                           → погружной насос колодца 220V

Логика:
  ┌─ Реле давления — ПЕРВИЧНАЯ защита (вкл/выкл по давлению бака)
  └─ Zigbee-реле — ВТОРИЧНЫЙ умный слой (вкл/выкл по расписанию/голосу)
  Zigbee-реле стоит ДО реле давления по линии фазы:
  L(автомат) → Zigbee-реле → реле давления → насос

Сценарии:
  «Утренний полив»: 06:00–07:00 — Zigbee-реле ВКЛ (насос работает по реле давления)
  «Авария протечки»: датчик протечки → Zigbee-реле ВЫКЛ → push-уведомление
  Голос: «Алиса, включи/выключи насос»
```

### 5.5в. Zigbee-реле 1-канал 10A — компрессор септика (Фаза 2)
```
Клемма L  ◄── от автомата «Септик» (10А)
Клемма N  ◄── от шины N

Выход ──► WAGO «СЕП-АЕР» → компрессор аэрации 220V (50–80Вт)

Сценарий «Аэрация по расписанию» (локальный Zigbee-таймер на шлюзе):
  08:00–22:00: 15 мин ВКЛ / 15 мин ВЫКЛ (циклический таймер)
  22:00–08:00: ВЫКЛ (ночной режим тишины)
  Голос: «Алиса, включи/выключи аэрацию»
```
### 5.6. Приёмник-реле 433 МГц (3 канала) — физический дублёр, ⚠️ важная схема
Радиоприёмник ставится **до** (выше по схеме) соответствующих каналов Zigbee-реле — так физический выключатель у входа может обесточить группу целиком, независимо от Zigbee/интернета/облака:

```
 Клемма L (вход) ◄── от автомата «Освещение» (10А), ПАРАЛЛЕЛЬНО с клеммой L Zigbee-реле 4к

 Канал 1 (клавиша 1 выключателя) ──► последовательно В РАЗРЫВ провода
                                      между гребёнкой и клеммой L входа
                                      CH1 участка Zigbee-реле (ОСВ-РАБ)
 Канал 2 (клавиша 2 выключателя) ──► аналогично, в разрыв перед CH2 (ОСВ-АНТ)
 Канал 3 (клавиша 3 выключателя) ──► в разрыв перед линией питания Yeelight-ламп

 Логика: клавиша в положении "выкл" физически снимает фазу с группы —
 Zigbee/голос не смогут включить свет, пока клавишу не вернут в "вкл".
 Это аварийный ручной оверрайд, а не альтернативный способ обычного управления.
```

> ⚠️ Хранить выключатель 433 МГц в положении «включено» по умолчанию в быту — Zigbee и Алиса управляют светом штатно. Клавишу переводят в «выключено» только вручную для аварийного обесточивания группы.

### 5.7. Шина N и шина PE
```
 Шина N (12 клемм): вводной N' → все группы получают ноль напрямую отсюда,
                     минуя автоматы и реле.
 Шина PE (12 клемм): от контура заземления здания → корпуса всех металлических
                     устройств (мотор экрана, корпус щита, камера) — НИКОГДА
                     не коммутируется через автомат или реле.
```

## 🧰 7. Пошаговая DIY-инструкция сборки

1. **Обесточить** место монтажа на вводном щитке дома/посёлка. Проверить отсутствие фазы индикаторной отвёрткой на месте будущего подключения.
2. Закрепить корпус щита на стене на высоте $1.5$ м, разметив отверстия по угловым крепежам корпуса.
3. Установить три DIN-рейки (ряды 1–3) в штатные пазы корпуса.
4. Смонтировать на ряд 1 слева направо: дифавтомат (модули 1–2) → 7 групповых автоматов (модули 3–9), из них модули 7–9 — заглушки до Фазы 1.5/2 → счётчик электроэнергии (модули 8–11), защёлкивая каждый модуль на рейку до щелчка.
5. Смонтировать на ряд 2: Zigbee-модуль штор (модули 1–3) → Zigbee-реле 4-канальное (модули 4–7) → шину N (модули 8–9) → шину PE (модули 10–11).
6. Прикрутить приёмник-реле 433 МГц к монтажной плате рядом с рядом 2 (саморезами, в стороне от DIN-реек).
7. Завести вводной кабель через кабельный ввод (гермоввод) в нижней/боковой стенке корпуса, зачистить и подключить к верхним клеммам дифавтомата: L — коричневый, N — синий.
8. Разводку фазы от дифавтомата к счётчику и от счётчика к 7 групповым автоматам (модули 3–9), выполнить гребёнкой или отрезками провода $2.5\text{ мм}^2$ — см. §3 и §5.1–5.3.
9. Подключить каждый групповой автомат к своей нагрузке согласно §5.4–5.6, используя WAGO для разветвлений вне щита (у экрана, у ленты, у розеток).
10. Подключить ноль (N) каждой группы напрямую с шины N, землю (PE) — напрямую с шины PE, минуя автоматы и реле.
11. Промаркировать все провода и клеммы по схеме §6 — до закрытия крышки щита, пока провода ещё доступны.
12. **Не закрывая крышку**, пригласить электрика для проверки вводного подключения и первого включения под напряжением (обязательный этап, см. врезку в начале документа).
13. После проверки электриком — включить дифавтомат, кнопкой «Тест» на нём проверить срабатывание УЗО (должен отключиться), затем включить обратно.
14. Поочерёдно включить каждый групповой автомат и мультиметром проверить наличие фазы на выходных клеммах.
15. Подключить Zigbee-модуль штор и Zigbee-реле к сети Zigbee через Tuya-шлюз (шлюз располагается **вне корпуса щита**, см. §9).
16. Подключить нагрузки: мотор экрана (см. Приложение 6, §5), группы освещения, розетки, чайник, ленту.
17. Настроить сценарии в приложении «Дом с Алисой» и Tuya/Smart Life согласно [Приложению 6, §7](ТЭО_Родовое_Поместье_Приложение_6_Умный_Дом_Алиса_Общий_Дом.md).
18. Провести полное тестирование по чеклисту §8, затем закрыть крышку щита.

## 🛠️ 9. Эксплуатация и устранение неисправностей

| Симптом | Вероятная причина | Решение |
|---|---|---|
| УЗО/дифавтомат постоянно выбивает | Утечка тока — влага в светильнике/проводке | Отключать группы по одной до выявления виновника, проверить герметичность LED-ленты и светильников |
| Zigbee-устройство не отвечает | Вне зоны действия сети / шлюз перезагружен | Добавить Zigbee-репитер (сама Yeelight-лампа работает как репитер), переприкрепить устройство к шлюзу |
| Алиса не слышит команду | Шумное помещение, большое расстояние до Станции | Говорить ближе к Станции 2, проверить что микрофоны не закрыты предметами |
| Экран не останавливается в нужном положении | Сбились концевые выключатели мотора | Отрегулировать концевики физически по инструкции производителя мотора — не связано с Zigbee-модулем |
| Подозрение на одновременное включение обоих каналов реле экрана | Неисправность/брак модуля интерлока | Немедленно обесточить группу «Экран» автоматом, заменить модуль по гарантии, не эксплуатировать до замены |
| Счётчик показывает 0 при явной нагрузке | Перепутана полярность/направление подключения | Проверить схему §5.2, направление стрелки, если используется выносной трансформатор тока |
| Чайник не реагирует на голос | Потеря Wi-Fi / сброшены настройки | Переподключить в приложении Tuvio/Tuya, проверить сеть 2.4 ГГц |
| Датчик дыма/протечки офлайн в приложении | Разряжена батарейка | Заменить батарейку (обычно CR2032/AAA в зависимости от модели) |
| RGB-лента не включается через голос, но включается кнопкой на контроллере | Клавиша 433 МГц физически обесточила линию | Вернуть клавишу оверрайда в положение «включено» |
| Групповой автомат «Розетки» отключается при одновременной работе усилителя и проектора | Кратковременный пусковой ток суммарно превышает 16А | Развести проектор и усилитель на разные умные розетки разных фаз распределения, либо повысить автомат группы до следующего номинала с пересчётом сечения провода |
| Прожектор не включается по движению | PIR-датчик разряжен / вне зоны Zigbee | Заменить батарею PIR, проверить расстояние до шлюза, добавить Zigbee-репитер на чердаке |
| Насос не отключается по протечке | Zigbee-реле зависло / датчик протечки офлайн | Проверить статус реле в приложении Tuya, заменить батарею датчика, реле давления остановит насос механически |
| Компрессор септика работает ночью | Сбился таймер на шлюзе / шлюз перезагружен | Перепроверить локальный сценарий в Tuya, убедиться что таймер локальный (не облачный) |
| PTZ-камера не поворачивается | Потеря Wi-Fi / питание отключено | Проверить роутер, проверить питание через умную розетку, перезагрузить камеру |
| Умный звонок не отправляет видео | Нет интернета / слабый Wi-Fi у входа | Установить Wi-Fi-репитер ближе к входной группе, проверить питание звонка |

## ⚠️ 10. Техника безопасности

1. **Все работы с вводным кабелем — только при обесточенном щите** и с проверкой отсутствия фазы индикаторной отвёрткой.
2. **Первое включение под напряжением — только с электриком.** Это единственный этап проекта, требующий стороннего специалиста; все остальные шаги выполняются самостоятельно.
3. **УЗО/дифавтомат обязателен** для купольного здания с деревянным/каркасным конструктивом — не эксплуатировать щит без него.
4. **PE (земля) никогда не коммутируется** через автомат, реле или выключатель — только прямое соединение с шиной заземления.
5. **Zigbee/Wi-Fi-хабы — вне металлического корпуса щита** (см. §9 выше и [Приложение 6, §6](ТЭО_Родовое_Поместье_Приложение_6_Умный_Дом_Алиса_Общий_Дом.md)): металл экранирует радиосигнал, устройства нужно располагать на открытой полке рядом.
6. **Вентиляция щита:** корпус IP41 с естественной конвекцией через нижние кабельные вводы; не устанавливать щит в закрытой нише без зазора $\geq 5$ см со всех сторон — Zigbee-реле греются под нагрузкой.
7. **Доступ к щиту** не должен быть загромождён мебелью — по нормативам должен обеспечиваться подход не менее $0.7$ м для экстренного отключения.
8. **Чайник (2200 Вт)** — всегда на дедикейт-линии, никогда не подключать через удлинитель или тройник от группы «Розетки».

## 🚀 11. Перспективные системы (Фаза 3 — видеонаблюдение и безопасность)

### 11.1. PTZ IP-камеры (2 шт.)

| Параметр | Значение |
|---|---|
| Тип | Уличная PTZ-камера, Wi-Fi 2.4 ГГц, IP66 |
| Питание | 220V через умную розетку Zigbee (группа «Розетки») или PoE (если доступно) |
| Совместимость | Приложение Tuya / интеграция с Алисой через навык Tuya |
| Размещение | Камера 1 — фасад, обзор входа и парковки; Камера 2 — тыл купола, обзор двора |
| Без интернета | ⚠️ Запись на SD продолжается, PTZ-управление и просмотр — нет |
| Модулей в щите | 0 (питание через существующую группу «Розетки», не требует отдельного автомата) |
| Бюджет | ~2 500–5 000 ₽/шт. на Ozon/WB (FloodCam, Tuya PTZ 1080p) |

> 💡 PTZ-камеры не занимают слоты в щите — питаются от розеток группы «Розетки». Сценарий: при срабатывании уличного PIR-датчика камера поворачивается в зону движения и начинает запись.

### 11.2. Умный дверной звонок

| Параметр | Значение |

| Без интернета | ⚠️ Кнопка звонка работает (физический звук), видео и уведомления — нет |
| Модулей в щите | 0 |
| Бюджет | ~2 000–4 000 ₽ на Ozon/WB |

### 11.3. Отопление — текущее состояние и перспективы

| Этап | Система | Умное управление |
|---|---|---|
| Текущее | Самодельная печь длительного горения (дрова/пеллеты) | ❌ Не автоматизируется — ручная загрузка топлива |
| Перспектива | Электрические конвекторы с Zigbee-термоголовками | ✅ Сценарии по расписанию, голосовое управление, удалённый прогрев перед приездом |
| Перспектива | Тёплый пол (водяной от печи/электрический) | ✅ Zigbee-термостат + реле циркуляционного насоса |

> ⚠️ Печь длительного горения — основное отопление на текущий момент. Переход на умное отопление возможен только после установки электрических конвекторов или гибридной системы. Резерв модулей в ряду 3 (позиции 3–12) обеспечивает этот переход без замены щита.

### 11.4. Водоснабжение — текущее состояние и перспективы

| Этап | Система | Условие запуска |
|---|---|---|
| Текущее | Водоснабжение не установлено | — |
| Перспектива | Колодец + погружной насос + гидроаккумулятор + реле давления | Тёплая пристройка-насосная достроена |
| Перспектива | Септик с аэрацией + компрессор по расписанию | Септик смонтирован, электрика заведена |

> ⚠️ Тёплая пристройка для насосного оборудования — обязательное условие Фазы 2 (водоснабжение). Без неё насос и гидроаккумулятор эксплуатировать в зимний период нельзя. Модули под насос и септик (ряд 1, позиции 7–8 и ряд 3, позиции 1–2) заложены в раскладку щита, но оборудование закупается и устанавливается только после готовности инфраструктуры.
