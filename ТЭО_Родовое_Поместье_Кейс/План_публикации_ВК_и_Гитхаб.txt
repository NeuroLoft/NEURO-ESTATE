ЧАСТЬ 1: КАК ОЧИСТИТЬ РЕПОЗИТОРИЙ GITHUB В БРАУЗЕРЕ (БЕЗ КОДА)

Поскольку ТЭО готово, вам нужно оставить на GitHub только папку с ТЭО и главный README проекта. Удалять файлы через браузер очень просто. Есть два способа.

Способ А (Самый быстрый и удобный — через встроенный редактор GitHub):
1. Откройте ваш репозиторий на GitHub в браузере.
2. Находясь на главной странице репозитория, нажмите на клавиатуре клавишу `.` (точка).
3. Прямо в браузере откроется веб-версия редактора (VS Code in Browser).
4. Слева вы увидите дерево всех ваших файлов и папок.
5. Выделяйте лишние папки (например, "Ипотека", "Мой кейс", "Проект РП", старые скрипты и т.д.), кликайте по ним правой кнопкой мыши и выбирайте "Delete" (Удалить).
6. Оставьте только папку `NEURO-ESTATE` (или конкретно `ТЭО_Родовое_Поместье_Кейс`) и корневой `README.md`.
7. После того как удалите всё лишнее, слева на панели нажмите на иконку "Source Control" (иконка с тремя кружочками и веткой, третья сверху).
8. В поле "Message" впишите: "Clean up repository, keeping only TEO core".
9. Нажмите синюю кнопку "Commit & Push". Готово! 

Способ Б (Обычный интерфейс GitHub, по одному файлу/папке):
1. Зайдите в репозиторий.
2. Откройте папку, которую хотите удалить.
3. В правом верхнем углу списка файлов нажмите на кнопку с тремя точками `...`
4. Выберите "Delete directory" (Удалить директорию).
5. Прокрутите страницу вниз и нажмите зеленую кнопку "Commit changes...".
6. Повторяйте для каждой лишней папки и файла.
